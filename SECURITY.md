# Security Policy

## Supported versions

Security fixes are handled on the default branch and included in the next published extension release.

## Reporting a vulnerability

Please do not open a public issue for suspected vulnerabilities.

Use GitHub private vulnerability reporting if it is enabled for this repository. If private reporting is not available, contact the repository owner privately through GitHub before sharing details publicly.

When reporting, include:

- Affected version or commit
- Steps to reproduce
- Impact and exploitability notes
- Any suggested fix or mitigation

## Scope

This project is a VS Code extension that reads local Claude Code usage logs and optionally calls user-configured external APIs. Reports involving accidental credential exposure, unsafe file handling, dependency vulnerabilities, or unintended network disclosure are in scope.
